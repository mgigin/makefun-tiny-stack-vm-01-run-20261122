# Tiny Stack VM

Entry for the make.fun bounty **tiny-stack-vm-01-run-20261122** ("Build a tiny
stack virtual machine"): an interpreter for make.fun's tiny stack ISA v1 in a
single `main.ts` (Node stdlib only, no WebAssembly). It runs every instance's
`program.bin` on its `input.bin` and writes `stdout.bin` + `exit.txt` per
instance, matching the reference VM's output bytes and exit codes — wrapping
32-bit arithmetic, all ten traps, step and output limits included.
